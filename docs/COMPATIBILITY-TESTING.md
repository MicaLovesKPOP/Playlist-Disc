# Compatibility testing

For every head unit or drive, record observations rather than assumptions.

Minimum test matrix:

1. finalized ordinary CD-R;
2. finalized CD-RW where the drive claims or appears to support it;
3. CD-TEXT enabled;
4. CD-TEXT omitted;
5. repeated cold-start recognition with the test disc left inserted;
6. eject/reinsert behavior;
7. any visible title, track, or duration rounding;
8. any TOC/metadata visible over the vehicle network or diagnostics;
9. audio-beacon playback/tap behavior if a fallback decoder is being evaluated.

Unknown is a valid result. Negative compatibility data is as useful as positive data.
