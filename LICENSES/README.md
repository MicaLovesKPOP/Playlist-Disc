# Licensing map

This draft repository is intended to use:

- **Apache-2.0** for software source and build/configuration files (`LICENSE`);
- **CC BY 4.0** for the normative specification and prose documentation;
- **CC0 1.0** for public catalog metadata so it can be mirrored and redistributed freely.

Before the first public release, full corresponding license texts should be added here and SPDX headers added where useful.
